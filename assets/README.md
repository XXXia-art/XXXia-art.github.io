# Assets

This directory is grouped by how each asset is used on the homepage.

- `profile/`: portrait and personal profile images.
- `interests/books/`: book covers and author-related images.
- `interests/movies/`: movie posters and film-related images.
- `badges/`: badge-wall icons for apps, tools, fandoms, and services.
- `affiliations/`: school, company, and organization logos.
- `social/`: social-platform icons.
- `decorative/`: decorative graphics used by interactions or cursors.
- `animations/`: Lottie JSON animations and motion assets.
